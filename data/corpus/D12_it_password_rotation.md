# Password rotation

Hello everyone, a short note from the IT team about passwords.

**No more forced password changes.** You do not have to change your password on a fixed schedule.
Forced regular changes lead people to pick weaker passwords, so we have switched this off.

**When you do need to change it.** Change your password only if you think it may have leaked, or
if IT asks you to because we saw signs of a problem.

**What stays the same.** Use a long password, keep it in the company password manager, and never
reuse it anywhere else. Multi-factor sign-in stays switched on for all work systems.

**Need help?** Ask in this channel or open a ticket at the help desk. We are happy to help you set
up the password manager.

Thanks for keeping Helios safe!
